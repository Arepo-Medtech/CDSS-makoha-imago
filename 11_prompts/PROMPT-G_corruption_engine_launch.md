# 0. Lever
**Lever 2.** G is the most silo-friendly component (G4): pure functions over schemas. The rulebook is the scarce asset and it already exists as a starter (G8, 18 rows, clinician red-pen invited). # 5. Design notes
- Interpretation: G's executable imperative is TASK-G-001 on rows 1–18 plus governance scaffolding; everything beyond row 18 is either dormant (23–25) or unspecified.
- Filed item flagged once: G9 cites "rows 1–30" but only 18 rows are specified anywhere in the repository (23–25 in K8; 26–30 named in L3 without perturbation definitions). The prompt refuses to invent the missing rows and files the gap for the rulebook owner.
- The report-header sentence about unsigned rows is the anti-laundering device: a green catch table on an unsigned rulebook must not be mistaken for the L2 exit criterion.
- If evals fail, change first: E8 gate attribution — outcome-only catch tables are the common shortcut.
