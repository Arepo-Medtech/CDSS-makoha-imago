# cdss-integration (Proposed home — Arch §10 allows "an integration repo (or the spine itself)"; DEC-09 names the home)
Carries the **integration lockfile** — one pinned version per repo (e.g. `engine 1.4.0 + library 2026.08.1 + dictionary 0.7 + policy 12 + graph g-2026.08 + conformal c-2026-07`) — and runs the **cross-component gauntlet** on any pin change: I's binding table, G's cross-suites, the property registry against the assembly. The lockfile IS the version-registry stamp: build reproducibility, runtime provenance, change control, dossier citation — one object, four uses (register law §12.1(4)).
Layout: `lockfile/` · `gauntlet/` (assembly-level CI importing cdss-evalstack) · `channels/` (release channels incl. GPP — see GPP-CHANNEL.md) · `rollback/` (redeploy prior pin-set; R14).
